# Contributing

Thanks for helping. Issues and pull requests are welcome; only maintainers push to `main` or make releases.

- **Bugs and ideas:** open an issue with your Windows version, the gadget, and what you expected.
- **Pull requests:** fork, branch from `main`, keep one change per PR, and run `cargo test` and
  `cargo build --release` first. A maintainer reviews every PR and must approve before it is merged.
- **CI on forks:** workflows from a first-time or outside contributor run only after a maintainer approves them.
- **Translations:** edit `assets/i18n/<lang>.json` (English text → your language). Keep `{}` placeholders.
- **Security problems:** do not open a public issue; see [SECURITY.md](SECURITY.md).

By contributing you agree that your work is released under the [MIT License](LICENSE).
