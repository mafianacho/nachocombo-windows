# Security

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/mafianacho/nachocombo-windows/security/advisories/new),
not in a public issue. Include the version, steps to reproduce and the impact you see.

Only the latest release gets fixes. Official builds come only from this repository's
[Releases](https://github.com/mafianacho/nachocombo-windows/releases); check them against `SHA256SUMS.txt`.
